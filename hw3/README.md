# ИДЗ-3. Сортировочная станция, вариант 49

Подлягин Данил Денисович, БПИ253.

Сборка и запуск в Linux или WSL из каталога hw3:

```sh
make
./station
./station-named examples/parallel.scenario 100
make test
```

Обе программы запускают дочерние процессы. station использует неименованные
POSIX-семафоры в общей памяти, station-named использует именованные.
Первый аргумент задаёт файл сценария, второй задаёт миллисекунды на единицу
времени модели. Ctrl+C останавливает моделирование. Журнал пишется в station.log.
Полный список параметров доступен через --help.

## Независимые процессы

В первом терминале запусти координатор:

```sh
./station-host examples/parallel.scenario 100
```

Он выведет `READY PID 8`, где PID - номер процесса координатора.
Во втором терминале из того же каталога подставь этот номер вместо 12345:

```sh
pid=12345
for slot in 0 1 2 3 4 5 6 7; do
    ./station-worker "$pid" "$slot" &
done
wait
```

Число после PID зависит от сценария. Слоты нумеруются с нуля. Координатор
даёт 30 секунд на подключение всех участников и не запускает их сам.
Для остановки нажми Ctrl+C в первом терминале.

Код 4 означает, что с выбранным планом продолжать нельзя. Стратегия
`first` отдаёт приоритет требованиям по порядку путей, `most` по их
вместимости. Если требования конкурируют за одни вагоны, результат может
различаться. Журнал показывает выбранную стратегию и число оставшихся вагонов.
