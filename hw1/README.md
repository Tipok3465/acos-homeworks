# Модель сортировочной станции

Учебный проект по курсу «Архитектура компьютера и операционные системы».
Программа воспроизводит расформирование прибывающих составов, маневровое
перемещение вагонов и сборку поездов по направлениям.

## Быстрый старт

```bash
make
./station
```

По умолчанию загружается `examples/station.scenario`, события появляются с
интервалом 1000 мс, а полная трасса выполнения сохраняется в `station.log`.
Запуск без анимационной задержки:

```bash
./station --scenario examples/station.scenario --delay-ms 0
```

Все параметры можно посмотреть командой:

```bash
./station --help
```

## Что можно наблюдать

Терминальное табло показывает прибытие состава, расцепку, назначение
локомотива, резервирование маршрута, начало и завершение манёвра, размещение
вагона, формирование и отправление поезда. Рядом отображается текущее заполнение
путей и занятость локомотивов.

Сценарий описывает топологию станции и исходные данные обычными текстовыми
строками. Например:

```text
track=2,north,4
locomotive=1,5.0
route=1,1,2,100.0,2
timing=2,2,4
strategy=first_fit
```

Полная спецификация формата приведена в `REPORT.md`.

## Самопроверка

```bash
make test
make examples
```

Первая команда запускает проверки загрузчика, инвариантов и вариантов
завершения. Вторая воспроизводит подготовленные рабочие сценарии и проверяет
временные отметки ключевых событий.

## Навигация по проекту

```text

scripts/               сценарии запуска проверок

```
